# 配置页面选择器

`ConfigPagePicker` 基于 shadcn `Select` 组合出 Janus 的配置摘要。弹层按配置分区分组，Web、Electron 与移动端使用一致的键盘和触摸交互。

<Canvas of={Stories.Card} />

## 变体

- `card`：独立放置时使用，带有背景、圆角和模糊材质。
- `inline`：嵌入已有圆角内容容器的标题区域，不重复创建卡片层级。

选项使用 `section → items` 结构映射为 `SelectGroup` 与 `SelectItem`，所以配置分区不会与具体配置页面混在同一层级。基础 Select 的维护文档位于独立的 `Shadcn/Select` 目录。
