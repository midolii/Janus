# 实时预览浮窗

`LivePreviewWindow` 只负责浮窗结构与交互，不建立网络连接，也不接触视频帧。业务层可以将 WebSocket、Electron IPC 或测试画布作为 `children` 注入。

<Canvas of={Stories.Floating} />

## 交互约束

- 关闭后保留可拖动入口；入口和浮窗始终被限制在视口安全区域内。
- 入口位置使用版本化的归一坐标保存在 localStorage 中，屏幕旋转或切换设备尺寸后仍能恢复到相近位置。
- 打开浮窗时根据入口所在象限选择展开方向，窗口不会超出屏幕边缘。
- 最小化将浮窗缩放为与入口同高的 44px 单行 Header，并根据窗口中心所在象限对齐当前窗口的对应角；媒体 Surface 保持挂载，避免重建 WebSocket，只有关闭浮窗才释放连接。
- 最小化 Header 不会宽于当前 resize 后的窗口，最大宽度为 496px；移动端还会受视口宽度减去两侧 16px 安全边距限制，并在旋转屏幕时重新计算。
- 恢复按钮使用加号语义，并通过 Motion 在减号与加号之间切换；恢复后回到最小化前记录的浮窗尺寸。
- 支持从左、右、下边缘和右下角调整尺寸。鼠标移动到左、右、下边缘时，中点会淡入对应的竖条或横条；左侧 resize 固定右边缘，其余方向固定 Header 左上角。关闭后清除尺寸，下次打开恢复默认大小。
- 入口按钮、普通窗口、最小化和全屏共用同一个 Motion 外壳；点击入口时是按钮本体扩大为窗口，而不是挂载第二个浮窗节点。
- 入口与普通窗口统一使用 22px 真实圆角，避免从 `999px` 插值时产生椭圆形中间态；窗口内容在几何展开后交错淡入，收起时入口内容延迟出现。
- 外壳的位置与尺寸只由 `x / y / width / height` 控制；关闭时根据窗口中心所在的视口象限，缩回窗口对应的左上、右上、左下或右下角，并将该位置保存为新的入口位置；再次打开时从同一角向屏幕内部展开。
- 全屏模式将媒体区域铺满页面视口，不显示 Header、圆角与窗口阴影；可以使用右上角按钮或 Esc 退出。
- Header 只保留单行标题与窗口操作；低频状态和错误固定显示在黑色媒体区域底部。
- 高频截图帧不得经过 React state、TanStack Query 或持久化 Store。
- 视口计算优先使用 `visualViewport`，用于适配 iOS Safari 动态工具栏和屏幕方向变化。
- 组件属于 Janus 组合组件，因此放在 `Business/Monitoring`，不与 `Shadcn` 基础组件混放。
